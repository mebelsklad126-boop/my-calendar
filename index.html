My Calendar

My Calendar — персональный Telegram-бот для работы с Google Calendar.

Приложение позволяет владельцу подключенного Google-аккаунта создавать события календаря и просматривать свое расписание через Telegram.

Доступ к Google Calendar

Приложение использует Google Calendar API исключительно для выполнения команд пользователя, связанных с его календарем.
